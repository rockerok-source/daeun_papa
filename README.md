# SOXL 루프투자법 아이폰 웹앱 (v4)

## 반영된 7가지 보완 사항
1. **그물추 단계 추가/삭제:** `LOC 매수 주문표` 상단의 `+ 그물추 추가` 버튼과 각 단계 우측의 `삭제` 버튼으로 그물추 칸수를 자유롭게 늘리거나 줄일 수 있습니다.
2. **기준 날짜 오늘 자동 설정:** 앱 실행 및 초기화 시 기기의 현재 날짜(`YYYY-MM-DD`)가 자동으로 입력되며, 필요 시 탭하여 수정할 수 있습니다.
3. **실현손익 미실현 오표시 해결:** 익절 매도 주문표는 예상 수익만 안내하며, 실제로 `익절` 버튼을 눌러 매매일지에 `매도`로 확정 기록된 건만 상단 `복리 배(SOXL) 총자산`의 `실현손익`에 합산됩니다.
4. **야후 파이낸스 전일 종가 연동:** `🔄 야후 파이낸스 전일 종가 자동조회` 버튼으로 SOXL·TQQQ 전일 종가를 자동 반영하고, 바로 확인할 수 있는 야후 파이낸스 직통 링크도 제공합니다.
5. **TQQQ 총 투자금 자동 계산:** `TQQQ 매수 단가($)`와 `TQQQ 보유 수량(주)`을 입력하면 `TQQQ 총 투자금($)`과 등대 비중이 자동으로 계산됩니다.
6. **물때 배수 직접 수정:** `오늘의 시장 기준 & LOC 설정` 카드에서 `썰물 하락 배수(배)` 및 `밀물 상승 배수(배)`를 바로 수정할 수 있습니다.
7. **상단 `저장` 버튼 추가:** 화면 우측 상단 초록색 `저장` 버튼을 누르면 입력한 모든 수치와 설정이 즉시 브라우저 저장소에 영구 저장되며 확인 알림이 표시됩니다.
