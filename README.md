# SOXL 루프투자법 아이폰 웹앱 (PWA)

다크 모드 기반 아이폰 사파리(Safari) 및 홈 화면 추가(PWA)용 SOXL 루프투자법 매수·매도 관리 웹앱입니다.

## 주요 기능
- **다크 모드 모바일 최적화 UI:** 아이폰 노치·하단 홈 인디케이터(`env(safe-area-inset-*)`) 대응 및 엄지손가락 중심 하단 탭 내비게이션.
- **총투자금 및 파라미터 실시간 수정:** 초기 총 투자원금(`$10,000` 기본), 등대(`TQQQ`) 비중, 배 분할 칸수(`18칸`), 썰물 배수(`2.5배`), 목표 익절률, 수수료율, 복리 시드 자동 연동(`Y/N`)을 언제든 변경 가능.
- **모든 숫자 직접 수정 가능:**
  - `LOC 주문` 탭: 전일 종가·물때 입력 시 그물(`-$0.01`) + 8단계 그물추(`-6.25% ~ -50.00%`) 자동 산출 및 각 행의 **지정가·배정액·수량** 직접 수정 및 즉시 `체결` 반영.
  - `보유묶음(Lot)` 탭: 묶음별 **매수가·수량·ID·일자** 직접 수정 및 저가 매수 묶음 우선 익절 청산.
  - `매매일지` 탭: 과거/신규 체결 내역의 **체결가·수량·매수가** 직접 수정 시 실현손익 및 복리 시드 자동 재계산.
- **로컬 저장 및 JSON 백업:** `localStorage` 자동 저장 및 상단 `백업` 버튼으로 JSON 파일 저장 가능.

## GitHub 업로드 및 아이폰 홈 화면 추가 방법
1. GitHub 새 저장소(Repository)를 생성합니다.
2. 아래 4개 파일을 저장소 루트에 업로드합니다.
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
3. 저장소 **Settings → Pages**에서 배포(Deploy from a branch → `main` / `/ (root)`)를 활성화합니다.
4. 아이폰 **Safari**에서 생성된 GitHub Pages 주소 접속 후 **공유 버튼 → 홈 화면에 추가**를 누르면 앱처럼 실행됩니다.
