# SOXL 루프투자법 아이폰 웹앱 (v2)

## 반영된 수정 사항
1. **스마트폰 한 화면 맞춤 레이아웃:** LOC 주문 페이지의 매수·매도 주문표를 좌우 스크롤 없는 2단 카드 그리드로 재배치해 아이폰 세로 화면에 한눈에 들어옵니다.
2. **초기화 시 모든 설정값 0으로 리셋:** 상단 `초기화` 버튼을 누르면 총 투자원금, 등대 투자금, 분할 칸수, 썰물 배수, 목표 수익률, 수수료율, 종가, 보유 묶음 및 매매일지가 모두 `0`(빈 목록)으로 초기화됩니다.
3. **등락률(%) 직접 수정 가능:** 그물 및 8단계 그물추 각 행의 `등락률(%)` 입력 칸을 수정하면 `LOC 지정가($)`와 `수량(주)`이 자동으로 재계산됩니다.
4. **TQQQ 등대 정보 표시 및 수정:** 상단 KPI와 LOC 주문 탭에서 `TQQQ 총 투자금($)`, `TQQQ 매수 단가($)`, `TQQQ 보유 수량(주)`을 직접 수정하고 실매수원금·평가손익을 바로 확인할 수 있습니다.
5. **LOC 익절 매도 주문표 항목 삭제 버튼:** 각 매도 주문 카드 우측 상단의 `삭제` 버튼으로 해당 묶음 항목을 즉시 삭제할 수 있습니다.
